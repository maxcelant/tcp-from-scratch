TCP From Scratch
15 lessons

A hands-on tutorial in Go

Build TCP from scratch.

Fifteen bite-sized lessons that take you from an empty Go module to a working TCP/IP stack — one that performs a real 3-way handshake, transfers data reliably over a lossy link, tears the connection down cleanly, and speaks HTTP/1.0 to a real server. Every byte produced by code you wrote.

Setup & plumbing

00Intro & SetupThe big picture, the TUN device, and the network model that makes the kernel your test peer. 01Opening a TUN deviceThe only package that touches the OS. Read and write raw L3 packet bytes.

The IP layer

02Parsing IPv4 headersBytes-in, struct-out. Decode the IPv4 header field by field. 03The Internet checksumRFC 1071 — the one function every other layer depends on. 04Serializing IPv4 + ICMP echoYour first program that sends packets. Make ping 10.0.0.2 work.

TCP fundamentals

05TCP header parse/serializeThe main event — including the pseudo-header checksum that trips everyone up. 06TCB & state machineModel TCP's brain: the 11-state FSM and the sequence-number bookkeeping.

The handshake & data flow

07Passive open: SYN → SYN/ACKThe read loop, demultiplexing by 4-tuple, and the first half of the handshake. 08Completing the handshakeHandle the final ACK, reach ESTABLISHED, and return a usable connection. 09Receiving data + ACKingIn-order delivery, the receive buffer, and Conn.Read as an io.Reader. 10Sending dataSegmentation, the send window, and Conn.Write — now io.Copy just works.

Reliability & teardown

11Retransmission (RTO)The feature that makes TCP reliable. Resend lost segments using a testable clock. 12Active open (client)tcp.Dial — send the first SYN and become a client. 13FIN teardownGraceful shutdown through FIN-WAIT, CLOSE-WAIT, LAST-ACK, and TIME-WAIT.

Capstone

14Speak HTTP/1.0curl-lite: connect to a real server, GET /, print the response. Proof you built TCP.
